# 💊 Tap & Talk

NFC 기반 스마트 복약 관리 시스템

## 프로젝트 소개

Tap & Talk는 NFC 태그를 활용하여 어르신의 복약을 기록하고,
보호자에게 실시간으로 복약 여부를 전달하는 서비스입니다.
